# Gusanos Calma — V6 Jardín

Versión visual y responsive preparada para continuar la validación educativa.

## Estructura
- `index.html`: juego.
- `assets/background/`: fondos del jardín.
- `assets/characters/`: personajes principales como recursos independientes y transparentes.
- `assets/companions/`: milpiés/ciempiés y compañeros.
- `assets/ui/`: estilos visuales.
- `assets/manifest.json`: inventario de recursos.

## Nota
Los SVG incluidos son recursos vectoriales independientes de respaldo. Pueden sustituirse por las ilustraciones PNG/WebP definitivas sin cambiar la arquitectura.
